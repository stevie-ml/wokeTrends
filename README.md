# wokeTrends

Testing Hanania's "Origin of Woke" institutional model with Google Trends: does Trump's April 2025 executive order targeting DEI produce a detectable, sustained decline in search interest for institutional DEI constructs — a shock to an institutional equilibrium rather than to mass opinion?

`analysis.py` collects Trends data, computes pre/post statistics with placebo-date and geography robustness checks, and generates the plots in `output/`.
